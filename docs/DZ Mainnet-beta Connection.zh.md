Solana 验证器通过本页面的步骤以 IBRL 模式连接到 DoubleZero。

每个 Solana 验证器都有自己的**身份密钥对**；从中提取的公钥称为**节点 ID**。这是验证器在 Solana 网络上的唯一标识。

确定 DoubleZeroID 和节点 ID 后，您需要证明对机器的所有权。这是通过创建一条包含 DoubleZeroID 并使用验证器身份密钥签名的消息来完成的。生成的加密签名可作为您控制该验证器的可验证证明。

最后，您将向 **DoubleZero 提交连接请求**。此请求传达的信息是：*"这是我的身份，这是所有权证明，这是我打算如何连接。"* DoubleZero 验证此信息，接受证明，并为该验证器在 DoubleZero 上配置网络访问权限。

本指南允许 1 个主验证器注册自身，并同时注册最多 3 台备份/故障转移机器。

## 前提条件

- 已安装 Solana CLI 并添加到 $PATH
- 对于验证器：在 sol 用户下有权访问验证器身份密钥对文件（例如 validator-keypair.json）
- 对于验证器：确认要连接的 Solana 验证器的身份密钥上至少有 1 SOL
- 防火墙规则允许 DoubleZero 和 Solana RPC 所需的出站连接，包括
 GRE（ip proto 47）和 BGP（169.254.0.0/16 on tcp/179）

!!! info
    验证器 ID 将通过 Solana gossip 进行检查以确定目标 IP。然后，目标 IP 和 DoubleZero ID 将在您的机器与目标 DoubleZero 设备之间建立 GRE 隧道时使用。

    注意：如果您在同一 IP 上同时有一个无效 ID 和主 ID，注册时只会使用主 ID。这是因为无效 ID 不会出现在 gossip 中，因此无法用于验证目标机器的 IP。

## 2. 开放端口 44880

用户需要开放端口 44880 以使用某些[路由功能](https://github.com/malbeclabs/doublezero/blob/main/rfcs/rfc7-client-route-liveness.md)。

要开放端口 44880，您可以更新 IP tables，例如：

```
sudo iptables -A INPUT -i doublezero0 -p udp --dport 44880 -j ACCEPT
sudo iptables -A OUTPUT -o doublezero0 -p udp --dport 44880 -j ACCEPT
```


注意 `-i doublezero0`、`-o doublezero0` 标志，将此规则限制为仅应用于 DoubleZero 接口

或使用 UFW，例如：

```
sudo ufw allow in on doublezero0 to any port 44880 proto udp
sudo ufw allow out on doublezero0 to any port 44880 proto udp
```


注意 `in on doublezero0`、`out on doublezero0` 标志，将此规则限制为仅应用于 DoubleZero 接口

## 3. 证明验证器所有权

!!! note "网络标志"
    以下 Passport 命令使用 `-u mainnet-beta`。在测试网上，请改用 `-u testnet`（或 `-ut`）。

设置好 DoubleZero 环境后，现在该证明您的验证器所有权了。

您在主验证器的[环境配置](setup.md)中创建的 DoubleZero ID 必须在所有备份机器上使用。

您主机器上的 ID 可以通过 `doublezero address` 找到。集群中所有机器的 `~/.config/doublezero/id.json` 中必须包含相同的 ID。

为此，您首先需要验证运行命令的机器是您的**主验证器**：

```
doublezero-solana passport find-validator -u mainnet-beta
```

这将验证验证器已注册在 gossip 中并出现在出块调度中。
