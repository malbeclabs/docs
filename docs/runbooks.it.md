# Runbook

Il DoubleZero MCP carica questo file dal raw di GitHub
(`https://raw.githubusercontent.com/malbeclabs/docs/main/docs/runbooks.md`)
per individuare le procedure guidate. Gli utenti utilizzano [Connetti la tua AI](mcp.md); non aggiungere questa
pagina alla navigazione del sito.

Per registrare un runbook, aggiungi un elemento alla lista sotto **Indice** con questa struttura:

```markdown
- `service-id` — [Titolo leggibile](page-slug.md)
```
