# Runbooks

El DoubleZero MCP carga este archivo desde GitHub raw
(`https://raw.githubusercontent.com/malbeclabs/docs/main/docs/runbooks.md`)
para descubrir guías paso a paso. Los usuarios utilizan [Conecta tu IA](mcp.md); no agregue esta
página a la navegación del sitio.

Para registrar un runbook, agregue un elemento de lista bajo **Índice** con esta estructura:

```markdown
- `service-id` — [Título legible](page-slug.md)
```
