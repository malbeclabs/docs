# DoubleZeroへようこそ

DoubleZeroは、ブロックチェーンなどの分散システム向けに最適化された高性能な分散型プロトコルおよびネットワークです。DoubleZeroのユーザーは、分散システムデータの高度に最適化された伝送と前処理のための統合サービスを利用できます。

## DoubleZeroは誰のためのものですか？

### コントリビューター

DoubleZeroのコントリビューターは、十分に活用されていないプライベートファイバーリンクやハードウェア（スイッチやFPGAデバイスなど）の形でネットワーク容量を保有しています。これらのリソースをDoubleZeroネットワークの拡張用に構成することで、統合された情報サービスが構築されます。DZプロトコルを使用して、ネットワークコントリビューターはこのネットワーク容量を動的で広範なグローバルメッシュネットワークに組み上げ、その貢献に対してトークンインセンティブを受け取ります。

### ユーザー

DoubleZeroのユーザーは、高性能なネットワーク接続を必要とするブロックチェーンなどの分散システムに参加しています。ブロックチェーンシステムをDoubleZeroと相互接続することで、ユーザーはネットワークI/Oを加速するための最適化機能のバンドルを得ることができます。

初期実装において、DoubleZeroネットワークはブロックチェーンバリデータークライアント、およびRPCやMEVインフラストラクチャプロバイダーと互換性があります。これらのユーザーシステムは、ネットワークへのアクセスを許可する前に、それぞれの台帳上で一意に識別する公開鍵アドレスを検証することでアドミッションコントロールを受けます。他のエコシステムのユーザーシステムを含むようにネットワークが進化するにつれて、各ユーザープロジェクトコミュニティに合わせた追加の識別・認証戦略が追加される予定です。

## メリット

DoubleZeroの唯一の代替手段はパブリックインターネットです。パブリックインターネットと比較して、DoubleZeroネットワークはブロックチェーンに2つの改善をもたらします。

*第一に*、インバウンドトランザクションは、DoubleZeroネットワークのユーザー（ブロックチェーンノードなど）に送信される前に、ネットワークコントリビューターのハードウェアレベルで非裁量的にエッジフィルタリング（スパムや重複の除去など）を行うことができます。これにより、各バリデーターが十分なリソースを個別にプロビジョニングする必要なく、ブロックチェーンはシステム全体で共有されたフィルタリングリソースの恩恵を受けることができます。その結果、バリデーターは直接収益を生み出す活動にリソースを再配分できます。この機能はまだ稼働していません。


*第二に*、アウトバウンドメッセージはより直接的にルーティングされ、効率を向上させるために優先されます。これは、DoubleZeroではグローバルデータ移動のルーティングロジックがパブリックインターネットとは異なり速度に最適化されているため可能です。したがって、バリデーターはジッター（2つのデータケーブルエンドポイント間のレイテンシーのばらつき）の低減の恩恵を受けます。本質的に、ブロックチェーンノードはブロックの送受信をより高速に行うことができます。

これらのDoubleZeroネットワークの利点を合わせることで、パブリックインターネットでは達成できないレベルのパフォーマンスを実現できます。
