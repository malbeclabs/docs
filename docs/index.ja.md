# DoubleZeroへようこそ

DoubleZeroは、ブロックチェーンなどの分散システム向けに最適化された高性能な分散型プロトコルおよびネットワークです。DoubleZeroのユーザーは、分散システムデータの高度に最適化された伝送と前処理のための統合サービスを利用できます。

## DoubleZeroは誰のためのものですか？

### コントリビューター

DoubleZeroのコントリビューターは、十分に活用されていないプライベートファイバーリンクやハードウェア（スイッチやFPGAデバイスなど）の形でネットワーク容量を保有しています。これらのリソースをDoubleZeroネットワークの拡張に利用するよう設定することで、統合された情報サービスが構築されます。DZプロトコルを使用して、ネットワークコントリビューターはこのネットワーク容量を動的かつ広範なグローバルメッシュネットワークに統合し、その貢献に対してトークンインセンティブを受け取ります。

### ユーザー

DoubleZeroのユーザーは、高性能なネットワーク接続を必要とするブロックチェーンなどの分散システムに参加しています。ブロックチェーンシステムをDoubleZeroと相互接続することで、ユーザーはネットワークI/Oを加速するための最適化機能のバンドルを得ることができます。

初期実装において、DoubleZeroネットワークはブロックチェーンのバリデータークライアント、およびRPCやMEVインフラストラクチャプロバイダーと互換性があります。これらのユーザーシステムは、ネットワークへのアクセスを許可する前に、各台帳上の一意に識別される公開鍵アドレスを検証することでアドミッションコントロールを受けます。ネットワークが他のエコシステムからのユーザーシステムを含むように進化するにつれて、各ユーザープロジェクトコミュニティに合わせた追加の識別および認証戦略が導入されます。

## メリット

DoubleZeroの唯一の代替手段はパブリックインターネットです。パブリックインターネットと比較して、DoubleZeroネットワークはブロックチェーンに対して2つの改善を提供します。

*第一に*、インバウンドトランザクションは、DoubleZeroネットワークのユーザー（ブロックチェーンノードなど）に送信される前に、ネットワークコントリビューターのハードウェアレベルで非裁量的な方法でエッジフィルタリングされます（スパムや重複の除去など）。これにより、ブロックチェーンは個々のバリデーターがそれぞれ十分なリソースを確保する必要なく、システム全体で共有されたフィルタリングリソースの恩恵を受けることができます。その結果、バリデーターはリソースを直接収益を生み出す活動に再配分できます。この機能はまだ実装されていません。


*第二に*、アウトバウンドメッセージは効率を向上させるためにより直接的にルーティングされ、優先順位が付けられます。これは、DoubleZeroではグローバルデータ移動のルーティングロジックがパブリックインターネットとは異なり速度に最適化されているため可能です。したがって、バリデーターはジッター（2つのデータケーブルエンドポイント間のレイテンシの変動量として定義される）の削減の恩恵を受けます。本質的に、ブロックチェーンノードはブロックをより速く送受信できます。

これらのDoubleZeroネットワークのメリットを合わせることで、パブリックインターネットでは達成不可能なレベルのパフォーマンスを実現できます。

詳細については、[DoubleZero Protocol](https://doublezero.xyz/whitepaper.pdf)のホワイトペーパーをご覧ください。
