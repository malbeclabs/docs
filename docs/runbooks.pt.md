# Runbooks

O DoubleZero MCP carrega este arquivo a partir do GitHub raw
(`https://raw.githubusercontent.com/malbeclabs/docs/main/docs/runbooks.md`)
para descobrir tutoriais passo a passo. Humanos usam [Conecte sua IA](mcp.md); não adicione esta
página à navegação do site.

Para registrar um runbook, adicione um item de lista em **Índice** neste formato:

```markdown
- `service-id` — [Título legível](page-slug.md)
```
