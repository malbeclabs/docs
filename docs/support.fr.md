# Support

Besoin d'aide pour vous connecter à DoubleZero ou pour opérer sur le réseau ? Commencez par vérifier l'état en direct, puis contactez l'équipe si vous avez encore besoin d'assistance.

## État des liens réseau

Vérifiez la santé actuelle des liens et la connectivité sur le portail de données DoubleZero :

**[Tableau de bord de l'état des liens](https://data.doublezero.xyz/status/links)**

Utilisez cette page pour confirmer si les problèmes que vous rencontrez sont généralisés à l'ensemble du réseau ou locaux à votre configuration avant de modifier quoi que ce soit.

## Contacter l'équipe

Si l'état semble normal (ou n'explique pas votre problème), ouvrez un ticket auprès de l'équipe DoubleZero sur Discord :

1. Rejoignez **[discord.gg/doublezerotech](https://discord.gg/doublezerotech)**
2. Ouvrez un **ticket de support** et décrivez le problème
3. Incluez ce que vous pouvez : environnement (mainnet / testnet), type de nœud, **IP du client**, commandes récentes et toute sortie d'erreur

!!! tip "Avant d'ouvrir un ticket"
    Le guide de [Dépannage](troubleshooting.md) couvre les échecs de connexion les plus courants. Le consulter en premier vous permet souvent de résoudre votre problème plus rapidement.
