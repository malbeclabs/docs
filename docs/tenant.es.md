# Tenants

Los tenants en DoubleZero son grupos de usuarios con perfiles y requisitos de conexión similares, que típicamente representan diferentes ecosistemas de blockchain, capas de transferencia de datos o sistemas distribuidos.

Examine la tabla a continuación y elija el caso de uso que mejor describa cómo planea interactuar con la Red DoubleZero.
