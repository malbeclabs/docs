# Runbooks

Le MCP DoubleZero charge ce fichier depuis GitHub raw
(`https://raw.githubusercontent.com/malbeclabs/docs/main/docs/runbooks.md`)
pour découvrir les guides pas à pas. Les utilisateurs consultent [Connecter votre IA](mcp.md) ; n'ajoutez pas cette
page à la navigation du site.

Pour enregistrer un runbook, ajoutez un élément de liste sous **Index** dans ce format :

```markdown
- `service-id` — [Titre lisible](page-slug.md)
```
