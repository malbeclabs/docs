# Hyperliquid

*概要*

Hyperliquid は DoubleZero 上で 2 つのプロダクトを提供しています: Edge マーケットデータフィード、および非バリデーティングノード向けピアリングです。

| 提供内容 | 概要 | 対象者 | ガイド |
| --- | --- | --- | --- |
| **マーケットデータフィード (Edge)** | DoubleZero Edge 上の UDP マルチキャストによる Top-of-Book および Market-by-Order。 | トレーダー | [Hyperliquid (Edge) の購読](edge.md) |
| **ピアリング** | Block Proxy 経由の重複排除済み Hyperliquid ゴシップフィード（マーケットデータなし）。 | 非バリデーティングノード | [ピアリングアクセス](peering.md) |

## マーケットデータフィード (Edge)

パブリッシャーがオーダーブックを再構築し、固定サイズのバイナリメッセージを DoubleZero Edge 上の UDP マルチキャストとして送信します。

コアフィードは Hyperliquid ネイティブ無期限先物（`hl`）および [trade.xyz](https://trade.xyz) 無期限先物（`xyz`）をカバーしています:

| フィード | 説明 |
|------|-------------|
| `hyper-hl-tob` | Hyperliquid 無期限先物のベストビッド/オファーおよび約定プリント |
| `hyper-hl-mbo` | Hyperliquid 無期限先物のフルオーダー単位板情報（追加、キャンセル、約定） |
| `hyper-xyz-tob` | trade.xyz 無期限先物のベストビッド/オファーおよび約定プリント |
| `hyper-xyz-mbo` | trade.xyz 無期限先物のフルオーダー単位板情報（追加、キャンセル、約定） |

- Top-of-Book およびトレード: 銘柄ごとのベストビッドとオファー、および約定プリント。
- Market-by-Order: すべてのレスティングオーダー（追加、キャンセル、約定）、インバンドスナップショットおよびデルタリカバリ付き。

複数のパブリッシャーを運用しているため、トレーダーはフェイルオーバーや最速ストリームの選択が可能です。

接続方法: [Hyperliquid (Edge) の購読](edge.md)。

## ピアリング

ピアリングは、マーケットデータを取得せずに Hyperliquid ゴシップが必要な非バリデーティングノード向けです。Block Proxy ティアとピアリングすることで、2 つの上流ゴシップソース（Hyper Foundation とセントリー）を 1 つの重複排除済みフィードに統合し、いずれかのソースがダウンしてもストリームが停止しないようにします。

各プロキシは、ノードから見ると通常のゴシップピアと同じように見えます。プロキシを追加することで容量を拡張でき、ピア数が増加してもノードへの負荷は増大しません。可用性目標は月間 99.9% です。このサービスには Edge マーケットデータフィードは含まれていません。

接続方法: [ピアリングアクセス](peering.md)。
